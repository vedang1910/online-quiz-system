# 📝 Online Quiz System

A web-based **Online Quiz System** developed using **PHP, MySQL, HTML, CSS, and JavaScript**. The application enables students to participate in quizzes while allowing administrators to manage questions and monitor results.

---

## 🚀 Features

### Student Module

- Student Registration
- Login System
- Attempt Quiz
- Automatic Result Generation
- Score Display

### Admin Module

- Secure Login
- Add Questions
- Manage Questions
- View Results
- Dashboard

---

## 🛠 Tech Stack
